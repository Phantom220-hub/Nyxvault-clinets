# DreamHouse 3D

Мобильный прототип приложения для проектирования домов на Godot 4.7.

## Уже реализовано
- Сенсорное и мышиное рисование стен на 2D-плане.
- Сетка и привязка точек к сетке.
- Отмена последней стены и очистка плана.
- Переключение между 2D-планом и базовым 3D-просмотром.
- Построение простых 3D-стен и пола по плану.
- Сохранение и загрузка проекта в JSON через user://.

## Запуск
Откройте папку проекта в Godot 4.7 или новее и запустите главную сцену.

## Дорожная карта
Следующие крупные функции: двери и окна с проёмами, мебельный каталог, редактирование размеров и материалов, камера с обходом помещения, несколько этажей, освещение и полноценный экспорт/импорт проектов.

Это рабочая начальная версия, а не законченная замена Home Design 3D.
