# DreamHouse 3D

Мобильный редактор планировки и базовой 3D-визуализации на Godot 4.7.

## Уже реализовано
- Тёмный мобильный интерфейс с бирюзовыми акцентами.
- 2D-план с сеткой, привязкой к сетке, линиями стен и подписями длины.
- Сенсорное рисование стен и отмена последней стены.
- Инструменты «ДВЕРЬ» и «ОКНО»: следующий нарисованный участок стены получает проём; проёмы строятся в 3D и помечаются на 2D-плане.
- 3D-сцена с процедурным небом, направленным светом, дополнительным освещением, полом и геометрией стен.
- Базовые 3D-модели дивана, кровати, стола, кресла и шкафа.
- Редактирование мебели прямо в 3D: выбор касанием, перемещение кнопками, поворот, масштабирование и удаление.
- Орбитальное управление 3D-камерой перетаскиванием; колесо мыши меняет дистанцию в desktop-режиме.
- Сохранение и загрузка проекта в JSON, включая несколько этажей.
- Создание дополнительных этажей и переключение между ними; у каждого этажа отдельные стены и мебель.
- Поиск замкнутых контуров стен и предварительный расчёт их площади по масштабу сетки.
- Режим прямого перемещения выбранной мебели пальцем по плоскости пола в 3D.
- Три визуальных пресета материалов: светлый камень, тёплое дерево и современный серый.

## Запуск
Откройте проект в Godot 4.7 или новее и запустите главную сцену.

## Честный статус
Это развиваемый прототип. Это всё ещё ранний прототип, а не готовая замена Home Design 3D. Дверные и оконные проёмы пока базовые: они задаются для следующей стены, без перетаскивания по уже построенной стене. Расчёт площади пока ищет замкнутые контуры по графу стен и является предварительным: сложные пересечения и контуры с внутренними перегородками могут считаться неточно. Пресеты материалов пока глобальные и не являются полноценным редактором материалов для каждого объекта. Импорт/экспорт файлов, полноценные дверные/оконные инструменты с размещением на существующих стенах и проверка на Android ещё не выполнены. Новые функции этажей, расчёта площади и прямого перемещения в 3D добавлены в исходники, но требуют проверки запуска и тестирования в Godot. Сборка APK и проверка в редакторе Godot пока не выполнены.
